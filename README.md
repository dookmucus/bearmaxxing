# BearMaxxing

A compact Kingshot Bear Hunt planner built with React, Vite, versioned JSON reference data, and an optional Netlify Function. It has no database, player authentication, analytics, or cross-device sync. Profile values and setup progress are saved automatically in this browser's local storage. If storage is unavailable, the app stays usable and shows a warning that changes cannot be remembered.

## Start locally

Requires Node 22.12 or newer.

```sh
npm install
npm run dev
```

The Vite address supports manual setup and planning. Optional Player ID import requires Netlify's local function runtime:

```sh
npx netlify-cli dev
```

Open the **Netlify** URL it prints, usually `http://localhost:8888`. Opening the Vite URL causes `/api/player/:id` to return the app's HTML fallback rather than invoke the function.

For local imports, create `.env` with `MIGHTPULSE_API_KEY=` and paste your provider key after the equals sign. `.env` is ignored by Git. Restart the Netlify runtime after changing the key. Never put a key in browser code or a `VITE_` variable.

## Calculator flow

Absolute damage forecasts and battle-report tracking are outside the product scope. Internal comparisons use normalized 10/10/80 relative offense; they neither need deployed troop counts nor use inventory-supported amounts as a substitute. Existing offline research scripts remain available for explicit observed-count audits, with no report-tracking workflow or forecast inputs in the app.

The [October 7 simplification verification](docs/simplification-verification-2026-10-07.json) records the individual failure review against the unchanged baseline, the two corrected calculation regressions, saved-input and recommendation checks, and the final serial result of 340 passing tests with no failures. Combat mechanics were not changed to satisfy tests.

First-time setup walks through Heroes, Gear, Masters, Pets, and Troops. It saves each change and the current step locally; fresh and established profiles open on Heroes, retaining saved values and setup completion. After setup, Home, Heroes, Gear, Masters, Pets, and Troops are available from the navigation. Home shows the supported hosting trio, simultaneous joining squads, shared troop needs, and a likely next priority. Unknown combat effects remain unknown. Optional Player ID import preserves manually confirmed values and excluded heroes without changing setup progress.

### Simultaneous marches
